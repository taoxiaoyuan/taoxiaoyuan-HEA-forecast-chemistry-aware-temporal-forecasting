# Result directory

- `temporal/`: rolling-window and dual-endpoint temporal evaluation.
- `validation/`: frozen-ranking validation, evidence cards, and Top-K statistics.
- `reliability/`: permutation, multi-seed, inter-reviewer, and sensitivity checks.
- `chemistry/`: composition-only chemistry and supply-burden screening.
- `method_comparison/`: topology, chemistry, semantic, and baseline comparisons.
- `wos_audit/`: public independent-index audit summaries and adjudicated labels.
- `figures/`: PNG visualizations generated from the included result tables.
