# Public derived data

- `discovery_events.csv`: normalized first-report HEA composition-reaction events.
- `performance_conditions.csv`: manually verified performance and testing conditions.
- `frozen_candidates.csv`: ranking frozen before the later literature audit.
- `ranked_candidates_with_labels.csv`: frozen ranking with validated outcome labels.
- `two_reviewer_labels_public.csv`: public label-only inter-reviewer table.

Raw abstracts, licensed database exports, PDFs, and private review keys are not
included. The abstract-derived `text_document` column has been removed from the
public candidate tables.
