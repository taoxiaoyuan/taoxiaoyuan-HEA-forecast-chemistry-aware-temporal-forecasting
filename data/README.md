# Public derived data

- `discovery_events.csv`: normalized first-report HEA composition–reaction events.
- `performance_conditions.csv`: manually verified performance and test conditions.
- `frozen_candidates.csv`: candidate ranking frozen before the later audit.
- `ranked_candidates_with_labels.csv`: frozen ranking with validated outcome labels.
- `two_reviewer_labels_public.csv`: de-identified label-only agreement table.

Raw abstracts, evidence sentences, licensed database exports, PDFs, private
review keys, and local PDF filenames are not included. Abstract-derived text
columns have been removed from the public candidate and result tables.
